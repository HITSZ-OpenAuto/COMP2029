## 课程内容
<!-- TOML-SECTION: title="课程内容" -->

<!-- TOML-ITEM: id="item-课程内容-1" -->

课程以导师课题分组带领学生的形式授课，需要在选课环节先选导师，进行学生导师互选。第一阶段为学生向倒是投递简历，有多个志愿，导师先选择学生（注意导师名额有限），如果第一轮所有志愿落选，会有补选阶段，以及教务部强制分配阶段。
课程可以做毕设相关内容，毕设导师不在授课教师名单内也可以联系老师进行答辩验收结课。注意有部分老师要求完成指定项目，这个在双选阶段即确定。但是大部分老师允许其他项目代替。
